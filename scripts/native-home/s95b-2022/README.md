# S95B Home-only source / Fuente de Casa para S95B

Sanitized .NET Core 3.1 helper used on Samsung QE65S95BATXXC, T-PTMDEUC-1720.7, Tizen 6.5 ARMv7. It assigns only the main/Home operation, preserving startup and resume preferences. `YourDining.CleanFrame` and `YourDining` are placeholders. The source checks exact firmware and SDK UID 901/32-bit; the private runner separately verified model over the TV API before staging. Implement equivalent model verification for another owner's transport. This source alone is not an installer or a supported transport for arbitrary TVs.

Fuente .NET Core 3.1 saneada del ayudante utilizado en esta S95B. Asigna solamente Casa y conserva arranque/reanudación. Los identificadores son ejemplos. El código comprueba firmware, usuario SDK 901 y 32 bits; el ejecutor privado verificó además el modelo antes de subir archivos. Mantén esa verificación al preparar un transporte propio. No es un instalador para cualquier TV.

Build the csproj with a compatible Microsoft SDK. Runtime .NET Core 3.1.3 was present on the tested TV. Actions: query; verify-baseline SNAPSHOT; apply-home SNAPSHOT; restore SNAPSHOT. Query output must be validated and saved once as a private immutable snapshot before apply. Do not overwrite original values. Restore only accepts the original or the chosen target Home and preserves the current startup/resume preferences. Each native apply needs owner authorization and physical verification. Keep keys, addresses, snapshots, generated assemblies and transport tools outside Git. Do not widen guards or use Tizen 9 helpers without review.

Compila con un SDK compatible; esta TV tiene .NET Core 3.1.3. Acciones: consulta, verificación, asignación y restauración con una copia original validada e inmutable. La restauración conserva las preferencias actuales de arranque y reanudación. Cada aplicación nativa necesita autorización y prueba física. Claves, direcciones, originales, compilados y transporte se conservan privados. No amplíes protecciones ni reutilices ayudantes Tizen 9 sin revisar.
